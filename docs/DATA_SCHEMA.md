# data.json — Schema v3.0.0

Generated by `scripts/fetch_data.py`. Dashboard contract; `app/src/data.ts`
mirrors these types. Every block produced by an official source carries
provenance via the top-level `sources` map and the `_pipeline.status` matrix.

## `subsurface_temp`

```
{
  lon: number[]              // 120.5 … 279.5 °E (GODAS grid)
  depth: number[]            // 5 … 262 m (≤ 300 m levels)
  lat: number[]              // 2°S–2°N band
  months: string[]           // "YYYY-MM" per time slice
  absolute: number[][][]     // [month][depth][lon] °C
  anomaly: number[][][]      // [month][depth][lon] °C vs 1991–2020 climatology
  thermocline_depth: number[][][] // [month][lon] m — 20 °C isotherm (null when absent)
  climatology: string|null   // reference period label
}
```

## Missing cells

GODAS uses fill values for land and below-bottom cells. The pipeline converts
them to NaN internally and:

- `absolute`: forward-filled along longitude (nearest ocean value),
- `anomaly`: neutralized to `0.0` (no anomaly where there is no ocean),
- `thermocline_depth`: `null` where the 20 °C isotherm cannot be determined.

## Provenance semantics

- `live` — parsed from the official source in this run.
- `derived` — computed by the pipeline from live fields (WWV, thermocline, anomalies).
- `synthetic` — official source unavailable (login wall / retired endpoint); the block
  is a deterministic schematic and the UI must display it as such.
- `error` — fetch crashed; block omitted.

## meta.json

Per-run health matrix: `health.<endpoint>.source|latency_ms|url|error|note` and
`summary` counts. Used for the README badge and the dashboard integrity bar.
